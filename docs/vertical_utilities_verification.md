## Проверка в Unity/Mono

Тестовый мод из `tools/validation/native-utilities/Probe.cs` запущен через `-batchmode -quicktest` с отдельным `-savedatafolder`. Пользовательские сохранения не загружались. Созданы настоящие карты 0/−1, закрытые комнаты, две батареи, лампа, термосекции, два бака Dubs и параллельные стояки.

Результаты:

- **Power PASS:** настоящие локальные PowerNet остаются разными, но удалённая батарея доступна потребителю; native solver расходует энергию один раз при вызове обеих сетей в том же тике. Параллельные столбы не дублируют батареи, владельцы компонентов сохранены.
- **Heat PASS:** реальная комната сверху охлаждается от входа снизу, источник получает соответствующее тепло; взвешенная суммарная энергия сохраняется. Закрытие входа останавливает перенос.
- **Plumbing PASS:** совпадение X/Z при закрытых стояках не связывает этажи. После открытия native PullWater расходует воду из настоящего удалённого бака и возвращает его загрязнение. Параллельный стояк не дублирует баки; разрыв возвращает локальные списки и сохраняет остаток источника.
- **Save/load PASS:** записано и загружено настоящее сохранение игры; восстановлены десять секций, клапаны, выбор источника −1, электрическая связность и 40 единиц воды. Повторное открытие труб позволяет забрать 10 единиц без дублирования остатка.

Native startup обнаружил неоднозначную перегрузку `ColonistBarDrawLocsFinder.CalculateDrawLocs`. Патч теперь выбирает точную публичную сигнатуру; повторный bootstrap и привязка Dubs прошли.

Тестовые логи/сохранение находятся локально в `obj/native-smoke-utilities` и исключены из дистрибутива. Временный тестовый мод убран из папки игры после проверки; пользовательский активный набор содержит Dubs перед DeepRim.
