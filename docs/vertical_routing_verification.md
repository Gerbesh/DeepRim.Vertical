## Исправления, обнаруженные при проверке

- `JobQueue.Peek()` нельзя вызывать при пустой очереди.
- На сгенерированной поверхности больше 1200 переносимых предметов: постоянное ограничение первыми 192 исключало поздние стопки. Порции поиска теперь сменяются.
- Для обычной кнопки запрета лестниц и её учёта в маршруте нужен `CompProperties_Forbiddable` в общей XML-базе лестниц/выходов.
- Стенд не должен вручную тикать частично загруженные карты. Он ожидает все long events; в batch mode пары лестниц создаёт непосредственно production-сервисом, обходя только ожидание невидимого окна загрузки.

## Практические границы

Проверка относится к первым адаптерам обычных колонистов, не ко всем работам RimWorld. Рецепты, потребности, животные/механоиды, сторонние work givers, общие богатство/события и бой между этажами ещё не интегрированы. Очередь проверена для команды движения по клетке; сложные задания с несколькими целями и драйверы сторонних модов требуют отдельной приёмки. Маршрут использует достижимость сегментов и оценку расстояния, не точную стоимость полного native path.
